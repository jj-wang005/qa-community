# QA Community Frontend

QA Community 的 Vue 3 + TypeScript 前端，与 FastAPI 后端一起存放在同一个仓库中。

## 功能

- 注册、登录、Access Token 刷新与退出。
- 问题热门/最新列表、问题详情、发布问题和回答。
- 回答点赞与采纳。
- AI 多轮会话、POST SSE 解析和会话 ID 保留。
- Agent `approval_required` 事件的批准/拒绝交互。
- 桌面端与移动端响应式布局。

## 本地启动

先启动 FastAPI 后端：

```powershell
cd ..
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

再启动前端：

```powershell
cd frontend
npm install
npm run dev
```

访问 `http://127.0.0.1:5173`。Vite 会将 `/api` 代理到 `http://127.0.0.1:8000`。后端同时默认允许 `localhost:5173` 和 `127.0.0.1:5173` 的跨域请求，其他部署地址通过后端 `.env` 中的 `CORS_ORIGINS` 配置。

## 验证

```powershell
npm run build
```

构建命令会先执行 Vue/TypeScript 类型检查，然后输出到 `dist/`。

## 生产部署

1. 在 `frontend/` 执行 `npm ci`、`npm test`、`npm run build`。
2. 将 `dist/` 放到静态服务器目录；参考 `nginx.conf.example` 修改根目录和现有后端地址。
3. 前后端使用同一个站点域名，`/api/` 反向代理到现有 FastAPI 服务。Vite 开发代理不包含在构建产物中。
4. 正式站点启用 HTTPS（可以由入口代理提供），AI 的 SSE 路由关闭代理缓冲并设置足够的读取超时。
5. 检查直接访问和刷新 `/questions/1`、`/assistant`，应返回前端页面而非服务器 404。

## 本轮完善

- 问题分页及 URL 中的排序/页码；回答热门、最新、已采纳筛选和分页。
- 作者对应的删除/采纳入口（最终授权仍由后端检查），删除前二次确认。
- 页面内存保留发布草稿（刷新即清空，主动退出时清除），登录后返回来源页、并发请求共享令牌刷新、注册/登录错误不触发刷新。
- 发布弹窗错误反馈、键盘焦点循环、Escape 关闭、空白输入与重复提交拦截。
- AI 响应式回复、新对话、停止等待、输入法回车保护、审批倒计时与过期禁用。
- SSE 分块边界、缩进与末尾事件处理，未知地址页面，移动端长内容折行。

停止等待只取消浏览器请求，不保证服务端推理或已提交操作停止。审批结果不明确时应核实回答的点赞状态。
后端没有总数接口，分页以返回满 20 条判断可能还有下一页，最后可能出现空页，可返回上一页。
当前没有后端全文搜索、内容编辑、密码找回或聊天历史接口，本前端不虚构这些能力。
自动化请求层测试使用模拟响应，不代表真实数据库和模型链路已验收。

## 个人中心

入口为顶部导航“个人中心”（手机端在菜单中），地址 `/profile`，未登录时跳转登录并保留返回地址。

- 显示当前用户名、字母头像和登录状态；支持快捷发布问题。
- “我的提问”使用现有问题列表接口，每次最多扫描 5 页、每页 100 条，以用户名筛选并按 ID 去重；未读完时提供“继续查找”，不会将部分结果标成全量统计。当前接口按发布时间排序，同一时间的记录或并发新增可能影响跨页稳定性，因此这不是生产规模的用户专属查询替代方案。
- “最近浏览”从新增功能后开始记录，按账户保存在当前浏览器中，最多 30 条，可清空。不是跨设备同步记录。
- 详情页支持返回个人中心原来的栏目，删除自己的问题时同步移除本地浏览记录。
- 未提供后端不支持的资料修改、头像上传、点赞全集入口。

### 我的回答

`/profile?tab=answers` 展示当前用户的回答正文、所属问题、回答时间、点赞数和采纳状态。点问题标题可打开对应回答所在页，并返回个人中心原栏目。

现有后端没有用户回答列表接口，前端分批遍历公开问题及其回答，每批最多 30 次请求，包含问题分页和回答分页。提供继续查找、失败重试、刷新、请求取消和 ID 去重，只显示“已找到”数量，不宣称部分结果为全部。跨分页的稳定性受现有后端排序影响；数据规模增长后应使用专用用户回答接口替代遍历，本轮没有修改后端。
